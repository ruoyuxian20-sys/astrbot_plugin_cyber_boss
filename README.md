# 🐷 小猪养成计划

> 全群共享的赛博 Boss 战：砍猪、攒钱、配装、抢 MVP，再看它满血复活。

`cyber_boss` 是一个不调用 LLM、零第三方运行时依赖的 AstrBot 群聊小游戏。每个群都有独立的 Boss、名人堂与玩家养成档案。

## 三步开始

```text
/砍猪                 # 先砍一刀，拿金币
/boss 商店            # 一张长图浏览全部商品
/boss 背包            # 购买后查看并装备道具
```

第一次游玩不需要配置。Boss 血量归零后会升级复活、血量成长 20%，所以它会越养越强。

## 你能玩到什么

| 系统 | 内容 |
|---|---|
| ⚔️ 共享 Boss 战 | 普通、暴击、闪避、反击、心软、神器六类随机事件 |
| 💰 个人经济 | 每次 `/砍猪` 都掉落金币；击杀按贡献发放猪神印记 |
| 🧩 自由配装 | 武器、副手、护具、饰品四栏可任意混搭，没有套装绑定 |
| 🛒 完整商店 | 56 件商品：8 个消耗品、48 件装备；默认一张长图完整浏览 |
| 🏅 荣誉称号 | MVP、补刀、双冠、事件成就均可解锁称号并提供加成 |
| 📜 群内记录 | 本轮排行、历代名人堂、个人战报和猎手阶位均按群独立保存 |

## 常用指令

### 战斗与战局

| 指令 | 作用 |
|---|---|
| `/砍猪` | 攻击 Boss，结算随机事件、装备效果、消耗品与金币掉落 |
| `/boss 状态` | 查看血条、等级、狂暴状态和本轮战况 |
| `/boss 排行` | 查看当前 Boss 的输出排行 |
| `/boss 名人堂` | 查看历代击杀记录 |
| `/boss 养 @某人` | 管理员换养新 Boss；当前战局重置，玩家资产保留 |

### 商店与背包

| 指令 | 作用 |
|---|---|
| `/boss 商店` | 一张长图浏览完整 56 件商品 |
| `/boss 商店 可买` | 只看当前阶位已解锁且余额足够的商品 |
| `/boss 商店 武器` | 也可替换为 `副手`、`护具`、`饰品`、`消耗品`、`金币`、`印记` 筛选 |
| `/boss 购买 <商品ID\|完整名称> [数量]` | 按稳定 ID 或完整名称购买 |
| `/boss 背包` | 查看货币、库存、已武装消耗品和当前配装 |
| `/boss 装备 <商品ID\|完整名称>` | 装备背包内的装备 |
| `/boss 卸下 <武器\|副手\|护具\|饰品>` | 卸下指定栏位 |
| `/boss 使用 <商品ID\|完整名称>` | 武装一个消耗品，作用于下一次实际结算的 `/砍猪` |

### 个人成长与帮助

| 指令 | 作用 |
|---|---|
| `/boss 我` | 查看个人战报、货币、猎手阶位、称号和关键加成 |
| `/boss 称号` | 查看已解锁称号与效果 |
| `/boss 佩戴称号 <称号ID>` | 选择一个称号生效；称号不叠加 |
| `/boss 帮助` | 查看完整总览 |
| `/boss 帮助 战斗` | 也可替换为 `商店`、`装备`、`称号` 阅读主题指南 |

## 战斗规则

| 事件 | 概率 | 效果 |
|---|---:|---|
| 普通 | 65% | 15–75 点伤害 |
| ⭐ 暴击 | 15% | 基础伤害 ×2–3 |
| 💨 闪避 | 10% | 本刀落空 |
| 🩹 反击 | 7% | 进入住院状态，暂时无法攻击 |
| 💗 心软 | 2.5% | Boss 回复 20–80 点血量 |
| ⚡ 神器 | 0.5% | `500 × Boss 等级` 伤害 |

Boss 剩余血量不高于 20% 时进入狂暴，反击概率翻倍；这也是狂暴／斩杀装备最适合出场的阶段。

## 金币、印记与猎手阶位

- 每次实际结算的攻击都会掉落金币；基础为 10 金币，另按伤害每 25 点 +1、最多额外 +30。闪避、反击、心软也有 10 金币保底。
- 击杀 Boss 时，造成过伤害的成员获得猪神印记：参与保底 + 贡献率奖励；MVP 额外 +4，补刀额外 +3。
- 同时拿下 MVP 与补刀会获得「双冠斩首」。
- 猎手阶位按本群累计输出成长，不受换养 Boss 影响。

| 阶位 | 累计输出 |
|---|---:|
| I · 见习猎手 | 0 |
| II · 熟练猎手 | 2,000 |
| III · 精英猎手 | 8,000 |
| IV · 传奇猎手 | 25,000 |
| V · 猪神猎手 | 70,000 |

金币主要购买常规装备和消耗品；猪神印记主要兑换 III–V 阶的强力装备。

## 装备与消耗品

四栏各只能装备一件，但可以自由混搭：

| 栏位 | 常见方向 |
|---|---|
| 武器 | 固定伤害、暴击、狂暴斩杀、神器伤害 |
| 副手 | 连击、神器触发、闪避重掷 |
| 护具 | 反击格挡、住院减免、心软处理、反击收益 |
| 饰品 | 金币、印记、MVP 和补刀收益 |

每栏有 6 件金币装备和 6 件印记装备。装备不会重复购买，也没有强制套装路线。

消耗品必须先通过 `/boss 使用 <ID>` 武装；冷却或住院导致攻击未结算时，消耗品不会被浪费。

## 称号

称号永久收藏，但一次只能佩戴一个。常见称号包括：

- `弑猪者LvN`：击杀次数越多，伤害加成越高。
- `主力输出`：本轮 MVP，提供暴击强化。
- `双冠斩首`：同轮 MVP 与补刀，提供金币加成。
- `小猪孝子`、`住院常客`、`代码术士`：来自特殊事件的成就称号。

## 配置

| 键 | 默认 | 说明 |
|---|---:|---|
| `initial_hp` | 10000 | 第 1 代 Boss 血量 |
| `hp_growth` | 1.2 | 每次击杀复活后的血量成长倍率 |
| `hospital_seconds` | 60 | 被反击后的基础住院时长（秒） |
| `attack_cooldown_seconds` | 900 | 同一玩家连续攻击的冷却（秒），默认 15 分钟；冷却中会显示剩余时间（同一人每分钟至多提醒一次） |
| `ranking_size` | 10 | 排行与名人堂显示条数 |
| `use_image` | false | 状态、背包、称号、个人页使用图卡；失败自动回退文本 |

## 安装与开发

将插件目录放入 AstrBot 的 `data/plugins/` 后重启 AstrBot；也可以使用本目录生成的 `cyber_boss.zip` 安装包。

```bash
python -m pytest tests -q
ruff check .
```
