# 小猪养成计划（cyber_boss）

小猪是全群共享 Boss：随手 `/砍` 一刀，随机事件与沙雕文案齐飞；血量清零即完成击杀，弑猪者进名人堂，随后 Boss **升级复活、血量 +20%**——越打越强，这就是「养成」。

纯本地随机引擎，**不调用 LLM**，零第三方依赖。

## 玩法

| 指令 | 说明 |
|---|---|
| `/砍`（`/打`、`/攻击`） | 核心动作，一个字开玩：伤害随机 + 实时血条 |
| `/boss 状态`（血条） | Boss 血条、等级、称号、狂暴标记、本轮战况 |
| `/boss 养 @某人` | 换养任意群友当小猪 Boss，从 Lv1 重新养成（仅机器人管理员可操作） |
| `/boss 排行` | 本轮对 Boss 的输出排行 |
| `/boss 名人堂` | 历代弑猪者记录（代数、耗时、总输出） |
| `/boss 我` | 个人战报：累计输出、事件统计、称号 |
| `/boss 帮助` | 使用说明 |

### 一刀下去可能发生什么

| 事件 | 概率 | 效果 |
|---|---|---|
| 普通 | 60% | 15–75 伤害，配随机沙雕文案 |
| ⭐ 暴击 | 15% | 伤害 ×2–3，抄起祖传键盘/冰红茶/60 秒语音… |
| 💨 闪避 | 10% | 小猪已读不回，攻击落空 |
| 🩹 反击 | 7% | 被禁言/被语音轰炸，「住院」期间不能砍 |
| 💗 心软 | 2.5% | 想起小猪的好，Boss 回血 20–80 |
| ⚡ 神器 | 0.5% | 掏出祖传的 main.py，500 × Boss等级 伤害 |

Boss 血量 ≤ 20% 进入**狂暴**：反击概率翻倍。

### 击杀结算

- 最后一刀者获「弑猪者Lv*N*」称号（随击杀数升级）
- 本轮输出第一授「主力输出」
- Boss 升级复活：Lv+1、血量 ×1.2、称号沿阶梯进化（新手小猪 → 已读不回猪仔 → … → 赛博暴猪 → 永恒猪神）
- 名人堂留名：代数、Boss 称号、弑猪者、全群总输出与耗时

### 成就称号

`弑猪者Lv{n}` / `主力输出` / `小猪孝子`（心软 5 次）/ `住院常客`（被反击 10 次）/ `代码术士`（触发过神器）

## 配置（WebUI 插件配置页）

| 键 | 默认 | 说明 |
|---|---|---|
| `initial_hp` | 10000 | 第 1 代 Boss 血量，人多可调大 |
| `hp_growth` | 1.2 | 每次击杀后的血量成长倍率 |
| `hospital_seconds` | 60 | 被反击后的住院时长 |
| `attack_cooldown_seconds` | 3 | 同一人两次砍之间的最小间隔（防刷屏） |
| `ranking_size` | 10 | 排行/名人堂条目上限 |
| `use_image` | false | `/boss 状态` 用 T2I 血条图卡，失败自动回退纯文本 |

## 开发

```

core/render.py    文本血条与图卡格式化
main.py           Star 入口：命令路由与事件 IO
tests/test_core.py 纯逻辑测试（不依赖 AstrBot 运行时）
```
